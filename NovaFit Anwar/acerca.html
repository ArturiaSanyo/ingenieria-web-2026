Acerca del gimnasio

NovaFit es una aplicación web temática creada para representar el proceso de registro de usuarios y afiliación a planes de gimnasio.

Objetivo

Facilitar el registro de personas interesadas en entrenar y permitirles solicitar una afiliación mediante el identificador generado por el sistema.

Autor

Anwar Joseph Palacios Bejarano — Ingeniería de Software.

Aplicación desarrollada con HTML, CSS, Node.js y SQLite.
